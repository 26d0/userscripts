# Jime's userscript junkyard

## How to Install

Install a userscript manager extension first:
- [Violentmonkey](https://violentmonkey.github.io/) (Recommended)
- [Tampermonkey](https://www.tampermonkey.net/)

Then click the install button below to add the script.

---

### Logseq Twitter Clipper

Clip tweets to Logseq via HTTP API.
You have to create a Logseq API token and add it to the userscript.

[![Install](https://img.shields.io/badge/Install-Logseq_Twitter_Clipper-blue?style=for-the-badge&labelColor=0366d6&color=0a3069)](https://raw.githubusercontent.com/26d0/userscripts/main/src/logseq.twitter.user.js)
