# JUJ
JUJ stands for **J**UJ's **U**serscript **J**unkyard

...or **J**imenshi's **U**serscript **J**unkyard

## How to Install

Install a userscript manager extension first:
- [Violentmonkey](https://violentmonkey.github.io/) (Recommended)
- [Tampermonkey](https://www.tampermonkey.net/)

Then click the install button below to add the script.

---

### Logseq Twitter Clipper

Clip tweets to Logseq via HTTP API.
You have to create a Logseq API token and add it to the userscript.

[![Install](https://img.shields.io/badge/Install-Logseq_Twitter_Clipper-blue?style=for-the-badge&labelColor=0366d6&color=85C8C8)](https://raw.githubusercontent.com/26d0/userscripts/main/src/logseq.twitter.user.js)

---

### SoundCloud RSS Feed

Grab RSS feed URL for SoundCloud user pages. Click the RSS button on a user's profile to copy their RSS feed URL to clipboard.

[![Install](https://img.shields.io/badge/Install-SoundCloud_RSS_Feed-blue?style=for-the-badge&labelColor=0366d6&color=FF5500)](https://raw.githubusercontent.com/26d0/userscripts/main/src/rss.soundcloud.user.js)
